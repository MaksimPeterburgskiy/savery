# Alembic migrations

This directory holds database migration scripts generated by Alembic. The environment is wired to SQLModel metadata in `backend/app/models.py`, so autogenerate works out of the box.

Typical commands (run from repository root with the backend virtualenv active):

```bash
alembic -c backend/alembic.ini revision --autogenerate -m "describe change"
alembic -c backend/alembic.ini upgrade head
```

The Alembic configuration reads the database URL from `SAVERY_DATABASE_URL` (via `backend.app.config.settings`).
